# C++ 算法与数据结构仓库

本仓库整理了常见的 C++ 算法题解、数据结构实现与练习代码，适合集训、刷题和复习。目录以中文分类，方便快速查找题型，并包含多个经典题目的实现示例。

## 仓库结构概览

- `Brute Force/`
  - 暴力枚举解法案例
  - 示例：`统计方形.cpp`

- `Data Structure/`
  - `队列/`
    - 队列基础、约瑟夫问题等题目
    - 示例：`找出游戏的获胜者(约瑟夫问题).cpp`
  - `链表/`
    - 单链表、环形链表、分割链表、反转链表、删除重复项、K 个一组反转、旋转链表等
    - 示例：`单向链表.cpp`、`环形链表.cpp`、`分割链表.cpp`、`删除重复项.cpp`、`K个一组反转链表.cpp`、`旋转链表.cpp`、`队列安排.cpp`
  - `树和二叉树/`
    - 二叉树遍历、路径和、叶子相似、每行最大值等
    - 示例：`路径总和2.cpp`、`叶子相似的树.cpp`、`在每个树行中找最大值.cpp`
  - `图论/`
    - DFS、BFS、最短路径、连通性等图论题目
    - 示例：`省份数量(深度优先搜索).cpp`、`网络延迟时间(迪杰斯特拉算法).cpp`、`迷宫(深度优先搜索).cpp`、`钥匙和房间(广度优先搜索).cpp`
  - `栈/`
    - 表达式解析、逆波兰表达式、括号有效性、最长有效括号、布尔表达式解析等
    - 示例：`最长有效括号.cpp`、`移除无效括号.cpp`、`解析布尔表达式.cpp`、`逆波兰表达式求值.cpp`

- `Greedy Algorithm/`
  - 贪心算法题目实现
  - 示例：`纪念品分组.cpp`

- `High-precision/`
  - 高精度运算与算法模板示例

- `Sort/`
  - 排序、二分查找、二叉搜索树、拼数字等问题
  - 示例：`在排序数组中查找元素的第一个和最后一个位置(二分查找).cpp`、`二叉搜索树的最近公共先祖(二叉排序树).cpp`、`拼数.cpp`、`sort函数的lamda表达式.md`

- `数据结构作业/`
  - 课程练习与作业题目汇总
  - 示例：`考试.cpp`、`考试2.cpp`、`考试3.cpp`、`考试4.cpp`、`考试5.cpp`、`考试6.cpp`

- `基本算法模板.md`
  - 常用算法模板、代码片段与快捷参考

## 编译与运行

仓库中的大多数代码为单文件 C++ 实现，可直接使用 g++ 编译：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count
./province_count
```

Windows 环境下：

```powershell
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count.exe
./province_count.exe
```

> 根据环境选择合适的标准和优化选项，例如 `-std=c++20`、`-O2` 等。

## 推荐学习顺序

1. 先从 `Data Structure/` 中复习基础数据结构
2. 再查阅 `Sort/`、`Brute Force/`、`Greedy Algorithm/` 等算法实现
3. 使用 `基本算法模板.md` 中的模板加速编写代码
