# 🚀 C++ 算法与数据结构学习仓库

这是一个用于记录常见 C++ 算法题解、数据结构实现和练习代码的个人学习仓库，适合用于刷题、集训和复习。

## 🎯 仓库目标

- ✅ 汇总常见算法题型与数据结构实现
- 📄 以单文件形式组织，便于快速阅读、编译和复盘
- 📚 覆盖排序、查找、动态规划、贪心、树、图、链表、栈、高精度等内容

## 🗂️ 目录结构

- `Brute Force`：🔎 暴力枚举类题目
- `Data Structure`：🧱 队列、链表、树、图、栈的实现与题解
- `DP`：♾️ 动态规划相关题目
- `Find`：🔍 查找算法
- `Greedy Algorithm`：🪙 贪心算法
- `High-precision`：🔢 高精度计算
- `Math`：➗ 数学相关题目
- `Simulation`：🎮 模拟题
- `Sort`：🧮 排序、二分查找与经典题练习
- `数据结构作业`：📝 课程作业与考试题

## ⚡ 快速开始

1. 在本仓库中选择你想练习的题目文件
2. 使用支持 C++17 的编译器进行编译
3. 运行生成的可执行文件，观察输出结果并调试

### 💻 编译运行示例

Linux / macOS：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count && ./province_count
```

Windows PowerShell：

```powershell
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count.exe; if ($?) { ./province_count.exe }
```

> ⚠️ 推荐使用 C++17 及以上编译器。

## 📈 推荐学习计划

1. 📘 先熟悉基础数据结构：链表、栈、队列
2. 🌲 再理解树与图的遍历与搜索：DFS、BFS、最短路径
3. 🧠 然后攻克核心算法专题：排序、查找、动态规划、贪心
4. 🏁 最后通过作业与考试题进行复盘，巩固边界条件与细节
