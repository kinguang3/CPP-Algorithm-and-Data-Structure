# C++ 算法与数据结构学习仓库

这是一个用于记录常见 C++ 算法题解、数据结构实现和练习代码的个人学习仓库，适合用于刷题、集训和复习。

## 仓库定位

- 汇总常见算法与数据结构题型
- 以单文件形式组织，便于阅读、编译和复盘
- 覆盖排序、查找、动态规划、贪心、树、图、链表、栈等内容

## 目录概览

- Brute Force：暴力枚举类题目
- Data Structure：队列、链表、树、图、栈的实现与题解
- DP：动态规划相关题目
- Find：查找算法
- Greedy Algorithm：贪心算法
- High-precision：高精度计算
- Math：数学相关题目
- Simulation：模拟题
- Sort：排序、二分与经典题练习
- 数据结构作业：课程作业与考试题

## 快速开始

### 编译运行示例

Linux / macOS：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count && ./province_count
```

Windows PowerShell：

```powershell
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count.exe; if ($?) { ./province_count.exe }
```

> 推荐使用 C++17 及以上编译器。

## 推荐学习顺序

1. 先掌握基础数据结构：链表、栈、队列
2. 再学习树与图的思维方式：DFS、BFS、最短路
3. 然后深入算法专题：排序、查找、动态规划、贪心
4. 最后通过作业与考试题进行复盘和查漏补缺

## 推荐阅读顺序

- 先看基本算法模板：基本算法模板.md
- 再按专题阅读对应目录中的题解
- 重点关注解题思路、复杂度分析和边界条件
