# C++ Algorithm and Data Structure

本仓库汇总了常见的 C++ 算法题解、数据结构实现和练习代码，适合作为刷题、复习和学习算法的参考资料。文件结构使用中文分类，方便快速定位题目类型。

## 目录说明

- `Brute Force/`
  - 暴力解法示例及相关题目
  - 示例文件：`统计方形.cpp`

- `Data Structure/`
  - `队列/`
    - 队列相关题目与约瑟夫问题
    - 示例文件：`找出游戏的获胜者(约瑟夫问题).cpp`
  - `链表/`
    - 单向链表、环形链表、分割链表、反转链表、删除重复项、K个一组反转链表、旋转链表等
    - 示例文件：`单向链表.cpp`、`环形链表.cpp`、`分割链表.cpp`、`删除重复项.cpp`、`K个一组反转链表.cpp`、`旋转链表.cpp`、`队列安排.cpp`
  - `树和二叉树/`
    - 树的遍历、路径总和、叶子相似、每行最大值等题目
    - 示例文件：`路径总和2.cpp`、`叶子相似的树.cpp`、`在每个树行中找最大值.cpp`
  - `图论/`
    - 深度优先搜索、广度优先搜索、最短路径、连通性等图论题目
    - 示例文件：`省份数量(深度优先搜索).cpp`、`网络延迟时间(迪杰斯特拉算法).cpp`、`迷宫(深度优先搜索).cpp`、`钥匙和房间(广度优先搜索).cpp`
  - `栈/`
    - 表达式解析、逆波兰表达式、括号有效性、最长有效括号、布尔表达式解析等
    - 示例文件：`最长有效括号.cpp`、`移除无效括号.cpp`、`解析布尔表达式.cpp`、`逆波兰表达式求值.cpp`

- `Greedy Algorithm/`
  - 贪心算法题目实现
  - 示例文件：`纪念品分组.cpp`

- `High-precision/`
  - 高精度运算与算法模板

- `Sort/`
  - 排序、二分查找、二叉搜索树、拼数等相关题目
  - 示例文件：`在排序数组中查找元素的第一个和最后一个位置(二分查找).cpp`、`二叉搜索树的最近公共先祖(二叉排序树).cpp`、`拼数.cpp`、`sort函数的lamda表达式`

- `数据结构作业/`
  - 课程作业或练习题汇总
  - 示例文件：`考试.cpp`、`考试2.cpp`、`考试3.cpp`、`考试4.cpp`、`考试5.cpp`、`考试6.cpp`

- `基本算法模板.md`
  - 常用算法模板与代码片段，便于复用

## 编译与运行

仓库中的大多数代码为单文件 C++ 实现，可直接使用 g++ 编译：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count
./province_count
```

如果你使用 Windows，请在命令行中运行：

```powershell
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count.exe
./province_count.exe
```

> 根据你的环境选择合适的 C++ 标准和编译器选项。例如 `-std=c++20`、`-O2` 等。
