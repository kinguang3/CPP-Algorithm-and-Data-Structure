# C++ Algorithm and Data Structure

这是一个汇总 C++ 算法与数据结构题解的仓库，包含常见题目、模板和练习代码，目录结构以中文分类，适合算法学习与刷题练习。

## 目录结构

- `Brute Force/`
  - 暴力解法示例与题目实现

- `Data Structure/`
  - `队列/`：队列、约瑟夫问题等
  - `链表/`：单向链表、环形链表、分割链表、反转链表、删除重复项等
  - `树和二叉树/`：树的遍历、路径总和、叶子相似等题目
  - `图论/`：深度优先搜索、网络延迟时间、省份数量等图论题目
  - `栈/`：表达式解析、逆波兰表达式、括号有效性、最长有效括号等栈相关题目

- `Greedy Algorithm/`
  - 贪心算法题目实现

- `High-precision/`
  - 高精度运算相关代码与算法模板

- `Sort/`
  - 排序与数值组合相关题目

- `数据结构作业/`
  - 课程或练习作业代码

- `基本算法模板.md`
  - 常用算法模板集合，方便复用

## 运行说明

本仓库中的代码大多为单文件 C++ 实现，编译方式示例：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count
./province_count
```

或

```bash
g++ -std=c++17 "Data Structure/图论/网络延迟时间.cpp" -o network_delay
./network_delay
```

> 请根据你的编译环境选择合适的 C++ 标准和文件路径。
