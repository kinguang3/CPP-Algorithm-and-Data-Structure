# C++ Algorithm and Data Structure

这是一个汇总 C++ 算法与数据结构题解的仓库，包含常见题目、模板和练习代码，目录结构以中文分类，适合算法学习与刷题练习。

## 目录结构

- `Brute Force/`
  - 暴力解法示例与题目实现
  - `统计方形.cpp`

- `Data Structure/`
  - `队列/`：队列、约瑟夫问题等
    - `找出游戏的获胜者(约瑟夫问题).cpp`
  - `链表/`：单向链表、环形链表、分割链表、反转链表、删除重复项、K个一组反转链表、旋转链表等
    - `单向链表.cpp`、`环形链表.cpp`、`分割链表.cpp`、`删除重复项.cpp`、`K个一组反转链表.cpp`、`旋转链表.cpp`、`队列安排.cpp`
  - `树和二叉树/`：树的遍历、路径总和、叶子相似、每行最大值等题目
    - `路径总和2.cpp`、`叶子相似的树.cpp`、`在每个树行中找最大值.cpp`
  - `图论/`：深度优先搜索、广度优先搜索、网络延迟时间、省份数量、迷宫等图论题目
    - `省份数量(深度优先搜索).cpp`、`网络延迟时间(迪杰斯特拉算法).cpp`、`迷宫(深度优先搜索).cpp`、`钥匙和房间(广度优先搜索).cpp`
  - `栈/`：表达式解析、逆波兰表达式、括号有效性、最长有效括号、布尔表达式解析等栈相关题目
    - `最长有效括号.cpp`、`移除无效括号.cpp`、`解析布尔表达式.cpp`、`逆波兰表达式求值.cpp`

- `Greedy Algorithm/`
  - 贪心算法题目实现
  - `纪念品分组.cpp`

- `High-precision/`
  - 高精度运算相关代码与算法模板

- `Sort/`
  - 排序、二分查找、二叉排序树与数值组合相关题目
  - `在排序数组中查找元素的第一个和最后一个位置(二分查找).cpp`、`二叉搜索树的最近公共先祖(二叉排序树).cpp`、`拼数.cpp`、`sort函数的lamda表达式`

- `数据结构作业/`
  - 课程或练习作业代码
  - `考试.cpp`、`考试2.cpp` ~ `考试6.cpp`

- `基本算法模板.md`
  - 常用算法模板集合，方便复用

## 运行说明

本仓库中的代码大多为单文件 C++ 实现，编译方式示例：

```bash
g++ -std=c++17 "Data Structure/图论/省份数量(深度优先搜索).cpp" -o province_count
./province_count
```

或

```bash
g++ -std=c++17 "Data Structure/图论/网络延迟时间(迪杰斯特拉算法).cpp" -o network_delay
./network_delay
```

> 请根据你的编译环境选择合适的 C++ 标准和文件路径。
